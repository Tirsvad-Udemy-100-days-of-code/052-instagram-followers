# Instagram Followers

A Selenium bot from Day 52 of the Udemy course "100 Days of Code: The Complete Python Pro Bootcamp". It logs in to the Share-a-Naan mock service, opens a target account and follows each of its followers.

The wiki follows the five steps of the lecture. Each page has the screenshots of the step and what we gained from it.

- [Step 1 - Credentials](Step-1-Credentials)
- [Step 2 - Class](Step-2-Class)
- [Step 3 - Login](Step-3-Login)
- [Step 4 - Find the followers](Step-4-Find-Followers)
- [Step 5 - Follow](Step-5-Follow)

Run it only against the mock service. The real Instagram can ban an account that behaves like a bot. See the README of the repository for the commands to install, run and test.
